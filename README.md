# Psychology

This repository examines various psychological topics using the cognitive metatheory of **mental symmetry** as a framework.

## About Mental Symmetry

Mental symmetry is a cognitive metatheory developed by Lorin Friesen. It proposes that the mind is organized into seven interacting cognitive modules:

| Module | Core Function |
|---|---|
| **Teacher** | Organizes abstract knowledge; builds general theories through language and logic |
| **Mercy** | Processes personal experiences, emotions, and relational identity |
| **Perceiver** | Identifies patterns and facts; evaluates truth and cause-and-effect |
| **Server** | Manages sequences, actions, and practical implementation |
| **Exhorter** | Provides motivation, energy, and creativity; connects ideas to consequences |
| **Contributor** | Integrates knowledge and process to set goals and manage resources |
| **Facilitator** | Mediates and integrates the other six modules; enables flexible thinking |

Every person possesses all seven modules, but one tends to be dominant, shaping their personality and preferences. Cognitive health and effectiveness increase as a person develops and balances all seven modules.
